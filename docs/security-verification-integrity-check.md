## 1. 기능 개요

### 1.1 보안 설정 화면

보안 설정 화면은 시스템의 보안 상태를 검증하고 파일 무결성을 확인하는 기능을 제공합니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  보안 설정                                                              [X] │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌──────────────────┐  ┌────────────────────────────────────────────────┐  │
│  │                  │  │                                                │  │
│  │  무결성 검사   ▶ │  │  ┌────────────────────────────────────────┐   │  │
│  │                  │  │  │        보안 검증 상태                    │   │  │
│  ├──────────────────┤  │  ├────────────────────────────────────────┤   │  │
│  │                  │  │  │                                        │   │  │
│  │  클라이언트 관리  │  │  │  ┌──────────────────┐                  │   │  │
│  │                  │  │  │  │ 자체 보안 검증 실행│    정상          │   │  │
│  └──────────────────┘  │  │  └──────────────────┘                  │   │  │
│                        │  │                                        │   │  │
│        사이드바         │  └────────────────────────────────────────┘   │  │
│                        │                                                │  │
│                        │  ┌────────────────────────────────────────┐   │  │
│                        │  │        무결성 검사 상태                  │   │  │
│                        │  ├────────────────────────────────────────┤   │  │
│                        │  │                                        │   │  │
│                        │  │  ┌──────────────────┐                  │   │  │
│                        │  │  │ 무결성 검사 실행  │    정상          │   │  │
│                        │  │  └──────────────────┘                  │   │  │
│                        │  │                                        │   │  │
│                        │  └────────────────────────────────────────┘   │  │
│                        │                                                │  │
│                        │                                      ┌──────┐ │  │
│                        │                                      │ 닫기 │ │  │
│                        │                                      └──────┘ │  │
│                        └────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 주요 기능

| 기능 | 설명 | 도구 |
|------|------|------|
| 자체 보안 검증 | 시스템 보안 설정 전체 검사 | ov-works-security_audit.sh |
| 무결성 검사 | 파일 시스템 무결성 확인 | AIDE (Advanced Intrusion Detection Environment) |

### 1.3 보안 검증 검사 항목

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      자체 보안 검증 검사 항목                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  1. 파일 권한 검증                                                   │   │
│  │     • engine.conf 파일 권한                                          │   │
│  │     • .pgpass 파일 권한                                              │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │  2. SSL/TLS 인증서 검증                                              │   │
│  │     • 인증서 유효성 확인                                              │   │
│  │     • 인증서 만료 기간 확인                                           │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │  3. 데이터베이스 보안 설정                                            │   │
│  │     • SSL 연결 설정                                                  │   │
│  │     • 패스워드 암호화 설정                                            │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │  4. 네트워크 보안                                                    │   │
│  │     • 방화벽 상태                                                    │   │
│  │     • SELinux 상태                                                   │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │  5. 인증 설정                                                        │   │
│  │     • AAA 설정 확인                                                  │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │  6. 감사 로깅                                                        │   │
│  │     • 감사 로그 설정 확인                                             │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │  7. 서비스 보안                                                      │   │
│  │     • 엔진 실행 권한 (non-root)                                       │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │  8. 파일 무결성                                                      │   │
│  │     • JAR 파일 체크섬 검증                                           │   │
│  │     (/usr/share/ovirt-engine/modules)                               │   │
│  ├─────────────────────────────────────────────────────────────────────┤   │
│  │  9. 백업 설정                                                        │   │
│  │     • 백업 구성 확인                                                  │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 5. API 명세

### 5.1 Action Types

| Action Type | Code | ActionGroup | 설명 |
|-------------|------|-------------|------|
| SecurityAudit | 2105 | AUDIT_LOG_MANAGEMENT | 자체 보안 검증 실행 |
| IntegrityVerification | 2106 | AUDIT_LOG_MANAGEMENT | 무결성 검사 실행 |
| SetTerminalAuth | 2110 | MANIPULATE_USERS | 단말기 인증 설정 |
| SetTerminalIpAuth | 2111 | MANIPULATE_USERS | IP 인증 설정 |

### 5.2 Query Types

| Query Type | Auth Type | 설명 |
|------------|-----------|------|
| GetTerminalAuthSerial | User | 단말기 일련번호 조회 |
| GetTerminalIpAuth | User | IP 인증 설정 조회 |
