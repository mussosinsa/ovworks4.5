## 1. 기능 개요

### 1.1 동시 접속 세션 수 기능

동시 접속 세션 수 기능은 단일 사용자가 동시에 유지할 수 있는 세션의 최대 개수를 제한하여 보안을 강화하는 기능입니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           세션 관리 화면 구성                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─────────────┐     ┌──────────────────┐     ┌─────────────┐              │
│  │   새로고침   │     │ 동시 접속 세션 수: N │     │  세션 종료   │              │
│  │     🔄      │     │       ▼          │     │     ✕       │              │
│  └─────────────┘     └────────┬─────────┘     └─────────────┘              │
│                               │                                            │
│                    ┌──────────▼──────────┐                                 │
│                    │  세션 제한 옵션       │                                 │
│                    ├─────────────────────┤                                 │
│                    │  ○ 1 세션           │                                 │
│                    │  ○ 2 세션           │                                 │
│                    │  ○ 3 세션           │                                 │
│                    │  ○ 4 세션           │                                 │
│                    │  ○ 5 세션           │                                 │
│                    └─────────────────────┘                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 주요 기능

| 기능 | 설명 |
|------|------|
| 세션 제한 설정 | 사용자당 1~5개의 동시 세션 허용 |
| 세션 종료 | 관리자가 특정 세션을 강제 종료 |
| 세션 모니터링 | 활성 세션 현황 실시간 조회 |
| 자동 세션 정리 | 만료된 세션 자동 정리 (1분 간격) |

### 2.4 세션 테이블 컬럼 설명

| 컬럼명 | 설명 |
|--------|------|
| 세션 DB Id | 세션의 고유 데이터베이스 식별자 |
| 사용자 이름 | 세션을 생성한 사용자명 |
| 인증 공급자 | 인증 방식 (internal-authz, LDAP 등) |
| 사용자 ID | 사용자의 고유 UUID |
| 소스 IP | 세션이 생성된 클라이언트 IP 주소 |
| 세션 시작 시간 | 세션이 생성된 시각 |
| 마지막 세션 활성 | 마지막으로 활동이 감지된 시각 |

## 5. API 명세

### 5.1 세션 관련 Action Types

| Action Type | Code | Description |
|-------------|------|-------------|
| `CreateUserSession` | 425 | 새 사용자 세션 생성 |
| `TerminateSession` | 410 | 특정 세션 종료 |
| `TerminateSessionsForToken` | 411 | SSO 토큰의 모든 세션 종료 |
| `SetEngineSessionLimit` | 7001 | 엔진 세션 제한 설정 |

### 5.2 세션 제한 설정 파라미터

```java
// SetEngineSessionLimitParameters
{
    "sessionLimit": 1-5  // 사용자당 허용 세션 수
}
```

### 5.3 세션 종료 파라미터

```java
// TerminateSessionParameters
{
    "sessionDbId": <Long>  // 종료할 세션의 DB ID
}
```

### 5.4 설정 파일

| 파일 | 설명 |
|------|------|
| `99-limit-user-sessions.conf` | 세션 제한 설정 저장 |
| `ENGINE_MAX_USER_SESSIONS` | 최대 세션 수 설정 키 |
