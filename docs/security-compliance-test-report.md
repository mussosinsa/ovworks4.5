## 1. 시험 개요

### 1.1 시험 목적

본 시험은 OV-Works(oVirt Engine 4.5.5)가 국가용 보안요구사항을 준수하는지 검증하기 위한 것으로, 국가·공공기관에서 사용하는 가상화 플랫폼의 보안성을 확인하고자 한다.

| 시험 항목 | 시험 방법 | 판정 기준 |

| AC-10 위임 제한 | 권한 위임 범위 제한 | 과다 위임 불가 |
| AC-11 세션 타임아웃 | 30분 미사용 시 자동 종료 | 타임아웃 동작 |
| AC-12 동시 세션 | 사용자당 세션 수 제한(1~5) | 초과 세션 차단 |
| AC-13 세션 무효화 | 로그아웃 시 즉시 무효화 | 재사용 불가 |
| AC-14 세션 검증 | 매 요청 시 세션 유효성 | 위조 세션 거부 |
| AC-15 강제 종료 | 관리자 강제 세션 종료 | 즉시 종료 확인 |

### 7.5 결론

- 네트워크 분리 및 암호화 영역에서 100% 충족
- Critical 취약점 없음
- 견고한 인증 및 접근통제 체계

개선 필요 사항:
- 관리자 계정 다중인증 필수화
- 패키지 보안 업데이트 적용
- SIEM 연동을 통한 실시간 모니터링

위 개선 사항을 이행한 후 재검증 시험을 통해 완전 합격을 취득할 것을 권고한다.
