## 1. 기능 개요

### 1.1 클라이언트 관리 화면

클라이언트 관리 화면은 시스템에 접근할 수 있는 단말기를 인증하고 IP 기반 접근 제어를 설정하는 기능을 제공합니다.

```

### 1.2 주요 기능

| 기능 | 설명 | 설정 파일 |
|------|------|----------|
| 단말기 인증 | 일련번호 기반 단말기 식별 및 인증 | /etc/ovirt-engine/encryptor/config.json |
| 단말기 IP 인증 | IP 주소 기반 접근 제어 | /etc/httpd/conf.d/z-ovirt-engine-proxy.conf |

### 1.3 인증 방식 비교

```
┌─────────────────────────────────────────────────────────────────────────────┐

│                         │                   │                              │

## 5. API 명세

### 5.1 Action Types

| Action Type | Code | ActionGroup | 설명 |
|-------------|------|-------------|------|
| SetTerminalAuth | 2110 | MANIPULATE_USERS | 단말기 일련번호 설정 |
| SetTerminalIpAuth | 2111 | MANIPULATE_USERS | IP 인증 설정 |

### 5.2 Query Types

| Query Type | Auth Type | 설명 |
|------------|-----------|------|
| GetTerminalAuthSerial | User | 현재 단말기 일련번호 조회 |
| GetTerminalIpAuth | User | 현재 IP 인증 설정 조회 |

### 5.4 설정 파일 경로

| 파일 | 경로 | 용도 |
|------|------|------|
| config.json | /etc/ovirt-engine/encryptor/config.json | 단말기 일련번호 저장 |
| proxy.conf | /etc/httpd/conf.d/z-ovirt-engine-proxy.conf | IP 인증 설정 |

### 5.5 정규식 패턴

| 용도 | 패턴 | 설명 |
|------|------|------|
| serialNum 추출 | `("serialNum"\s*:\s*")([^"]*)(")` | JSON에서 serialNum 필드 값 추출/수정 |
| Require ip 추출 | `(?m)^\s*Require\s+ip\s+.*$` | Apache 설정에서 Require ip 라인 추출/수정 |
