관리 엔진 서비스가 중단되었습니다

HTTP 503 Service Unavailable — 웹 서버는 동작 중이며, 관리 엔진이 응답하지 않습니다.

관리화면을 사용할 수 없습니다. 관리 엔진 서비스가 실행되고 있지 않습니다.

보안 검증 실패 시의 대응: 서비스 중단

이 시스템은 관리 엔진을 기동하기 전에 자체 보안 검증을 필수로 수행합니다. 검증에 실패하면 엔진 데몬을 기동하지 않고 서비스를 중단하며, 중단 시각과 사유를 기록합니다. 따라서 이 화면은 보안 검증 실패에 대한 대응이 적용된 상태에서도 표출됩니다.

보안 검증 실패로 기동이 차단된 경우, 기록된 사유는 서비스가 복구된 뒤 관리화면의 보안 설정 → 보안 검증 실패 대응 (서비스 중단) 항목과 감사기록(SECURITY_VERIFICATION_SERVICE_HALTED)에 표출됩니다.

조치

  • 보안 검증 실패 항목을 해소한 뒤 systemctl start ovirt-engine으로 재기동하십시오.
  • 다른 보안 검증(예약 감사 또는 관리화면 실행)이 진행 중이어서 차단된 경우에는 해당 검증이 끝난 뒤 다시 기동하십시오.
  • 차단 사유는 다음 정상 기동 시 감사기록에 자동으로 표출되므로, 별도로 기록을 옮길 필요는 없습니다.

이 화면은 관리 엔진이 아니라 웹 서버가 제공합니다. 등록된 관리 단말에서만 조회할 수 있습니다.
